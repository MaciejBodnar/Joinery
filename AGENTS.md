# Joinery Atelier Theme Development Guide

This is a **Roots Sage** WordPress theme with modern development tooling and Laravel-powered PHP templating. This guide helps AI agents understand the project structure and conventions.

## Quick Reference

- **Framework**: [Roots Sage](https://roots.io/sage/) (modern WordPress starter theme)
- **PHP Version**: 8.3+
- **Node Version**: 20.19+ or 22.12+
- **Build Tool**: [Vite](https://vitejs.dev/) with Tailwind CSS
- **Templating**: [Laravel Blade](https://laravel.com/docs/blade)
- **CMS Features**: ACF (Advanced Custom Fields), Block Editor support, i18n translation

## Project Structure

```
app/                    # PHP app code (PSR-4 autoloaded from App\ namespace)
├── setup.php          # Theme setup, hooks, and configuration
├── filters.php        # Custom filters and modifications
└── Providers/         # Service providers for dependency injection
    ├── ThemeServiceProvider.php
    └── ACFFieldProvider.php

resources/             # Frontend assets and templates
├── css/               # Stylesheets (app.css, editor.css, typekit.css)
├── js/                # JavaScript modules
│   ├── app.js        # Main entry point
│   ├── editor.js     # Block editor scripts
│   ├── accordion.js  # Component-specific JS
│   └── gallery.js
├── fonts/            # Custom fonts
├── images/           # Static images
└── views/            # Blade template files (compiled to HTML)
    ├── layouts/      # Page layout templates
    ├── sections/     # Reusable content sections
    ├── partials/     # Shared template partials
    ├── front-page.blade.php
    └── template-*.blade.php

public/build/         # Built assets (auto-generated, don't edit)
├── manifest.json     # Vite asset manifest
└── assets/           # Compiled CSS/JS/fonts

vendor/               # Composer dependencies (auto-generated, don't edit)

functions.php         # Theme entrypoint - loads Acorn and composers
index.php            # WordPress fallback template
theme.json           # WordPress block editor settings (generated by Vite)
style.css            # Theme header (required by WordPress)
```

## Key Development Commands

| Command                     | Purpose                                              |
| --------------------------- | ---------------------------------------------------- |
| `npm run dev`               | Start Vite dev server with hot reload                |
| `npm run build`             | Build production assets (Tailwind + JS minification) |
| `npm run translate:pot`     | Generate `.pot` translation template                 |
| `npm run translate:update`  | Update `.po` translation files                       |
| `npm run translate:compile` | Compile translations to `.mo` and JSON               |
| `./deploy-production.sh`    | Build and create timestamped deployment folder       |

## Important Conventions

### 1. **Blade Templating**

- All `.blade.php` files in `resources/views/` are compiled by WordPress
- Use Blade syntax: `{{ $variable }}`, `@if`, `@foreach`, `@component`, etc.
- Layout inheritance: `@extends('layouts.app')` and `@section('content')`
- See `resources/views/layouts/` for base template structure

### 2. **Asset Imports**

Vite aliases are configured in `vite.config.js`:

- `@scripts` → `resources/js`
- `@styles` → `resources/css`
- `@fonts` → `resources/fonts`
- `@images` → `resources/images`

Example in JS/CSS:

```javascript
import '@styles/app.css';
import { myModule } from '@scripts/accordion.js';
```

### 3. **Block Editor Integration**

- Custom editor styles: `resources/css/editor.css`
- Custom editor scripts: `resources/js/editor.js`
- Automatically injected via `app/setup.php`
- `theme.json` is auto-generated from Tailwind config (do not edit directly)

### 4. **PHP Namespace and Autoloading**

- All app code is in `App\` namespace (PSR-4)
- Configured in `composer.json`: `"autoload": { "psr-4": { "App\\": "app/" } }`
- Run `composer dump-autoload` after adding new files

### 5. **Service Providers**

- `ThemeServiceProvider.php` - Main theme setup
- `ACFFieldProvider.php` - ACF field configurations
- Auto-registered by Acorn in `functions.php`

### 6. **Internationalization (i18n)**

- Translation strings use `__('text', 'sage')` or `_e('text', 'sage')`
- Translation files stored in `resources/lang/`
- Workflow: extract → update → compile

## Common Pitfalls & Solutions

| Issue                         | Solution                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| Assets not loading in dev     | Run `npm run dev` first; check Vite is running on correct port                              |
| Blade templates not compiling | Ensure `functions.php` loaded; check `app/setup.php` hooks                                  |
| ACF fields not showing        | Verify field registration in `app/Providers/ACFFieldProvider.php`                           |
| Deployment missing files      | Check `deploy-production.sh` for which files are copied; ensure all needed files are listed |
| Composer autoload stale       | Run `composer dump-autoload` after new files in `app/`                                      |
| Tailwind classes not applied  | Run `npm run build` if in production; check `tailwind.config.js` for content paths          |

## Deployment

- **Development**: `npm run dev` for hot reload during local development
- **Production Build**: `npm run build` generates minified assets
- **Deploy**: Use `./deploy-production.sh` which:
  1. Builds production assets
  2. Creates timestamped folder (e.g., `joinery-atelier-20250510-1430`)
  3. Copies essential theme files

## File Modification Guidelines

- ✅ **Edit**: `app/`, `resources/`, `style.css`, `theme.json` (edits to base template)
- ❌ **Don't edit**: `public/build/` (auto-generated), `vendor/` (dependencies)
- ⚠️ **Careful**: `functions.php` (entry point) - test thoroughly
- ✅ **Safe**: Blade templates - hot reload in dev mode
